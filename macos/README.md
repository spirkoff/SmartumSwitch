# SmartumSwitch для macOS (MVP 0.1)

Бесплатно, без подписи Apple и без аккаунта разработчика. macOS 13 и новее, Intel и Apple Silicon.
Нужны раскладки «Английская» (U.S. или ABC) и «Русская» (лучше **«Русская — ПК»** / RussianWin — она совпадает
с раскладкой Windows, на которую рассчитано ядро; проверка: `--layout-check`, см. ниже).

## Что умеет
- Автоисправление на лету: `ghbdtn ` → `привет `, `руддщ ` → `hello `; раскладка переключается сама.
- Backspace сразу после исправления — откат (и это слово больше не трогается до перезапуска).
- **Pause** — исправить выделенное (или последнее слово, если ничего не выделено).
  На PC-клавиатуре (A4tech и т. п.) macOS видит Pause как **F15** — по умолчанию это и есть клавиша SmartumSwitch
  (яркость экрана она больше не меняет). **Shift+Pause** — включить/выключить автоисправление.
- Значок **S** в строке меню (S· — пауза): состояние, вкл/выкл, «Исключения…», журнал, разрешения, автозапуск, выход.
- Не трогает: Терминал, iTerm2, kitty, Alacritty, Warp, WezTerm, Ghostty, менеджеры паролей, «Связку ключей»,
  окна входа; любые поля пароля (Secure Input и AX-поле пароля); окна с «пароль/password/sudo…» в заголовке;
  сочетания с Cmd/Ctrl/Option.
- Если запущены **Caramba Switcher** или **Punto Switcher**, автоисправление SmartumSwitch само встаёт на паузу
  (значок S·), чтобы два переключателя не исправляли одно слово дважды. Ручное (Pause) работает.
- Приватность: набранный текст нигде не сохраняется и никуда не отправляется. Журнал
  `~/Library/Logs/SmartumSwitch/smartum-switch.log` — только счётчики и ошибки.
- Исключения: `~/Library/Application Support/SmartumSwitch/exceptions.txt` (по слову в строке, подхватываются сами).

Ядро общее для всех систем (`core/`): те же правила, словари hunspell (вшиты в приложение) и 171 тест.

## Сборка (на самом Mac)
Нужны только **Command Line Tools** (бесплатно; Xcode не нужен). Проверка: `xcode-select -p` →
`/Library/Developer/CommandLineTools`. Если их нет — `xcode-select --install` (около 1–2 ГБ, ставит сам пользователь).

```bash
cd ~/SmartumSwitch/macos      # рядом должна лежать папка core/
./build.sh                    # → macos/_app/SmartumSwitch.app, в конце прогоняет 171 тест ядра
```
Скрипт ничего не устанавливает и не меняет вне папки `macos/` (временные файлы — `macos/_obj/`).
Подпись — только локальная ad-hoc (`codesign -s -`), бесплатно.

Проверка раскладок (ничего не меняет): `_app/SmartumSwitch.app/Contents/MacOS/SmartumSwitch --layout-check`.

## Установка и первый запуск
1. Скопировать `macos/_app/SmartumSwitch.app` в `~/Applications` (папка программ пользователя, пароль не нужен):
   `mkdir -p ~/Applications && cp -R _app/SmartumSwitch.app ~/Applications/`
2. Выключить другой переключатель (Caramba: значок в строке меню → «Выход»), иначе SmartumSwitch будет на паузе.
3. Запустить: `open ~/Applications/SmartumSwitch.app` — в строке меню появится **S·**.
4. Дать два разрешения (ниже). Через несколько секунд после разрешений значок станет **S** — работает.

## Разрешения (их даёт только сам пользователь)
SmartumSwitch видит нажатия клавиш и печатает исправленное слово — для этого macOS требует два разрешения.

**1. Универсальный доступ (Accessibility)**
1. При первом запуске macOS сама покажет окно «SmartumSwitch хочет управлять этим компьютером…» →
   «Открыть Системные настройки». (Или меню **S·** → «Разрешение «Универсальный доступ»…».)
2. Системные настройки → **Конфиденциальность и безопасность** → **Универсальный доступ**.
3. Найти **SmartumSwitch** в списке и включить переключатель. Если его нет — кнопка **«+»** внизу → выбрать
   `~/Applications/SmartumSwitch.app` → «Открыть» → включить.
4. macOS попросит пароль или Touch ID — это вводит сам пользователь.

**2. Мониторинг ввода (Input Monitoring)**
1. Системные настройки → **Конфиденциальность и безопасность** → **Мониторинг ввода**
   (или меню **S·** → «Разрешение «Мониторинг ввода»…»).
2. Включить **SmartumSwitch** (или «+» → `~/Applications/SmartumSwitch.app`).
3. Если macOS предложит «Выйти и открыть снова» — согласиться.

Важно: подпись ad-hoc меняется при каждой пересборке, поэтому **после новой сборки** разрешения нужно снять
(«–») и выдать заново, иначе macOS будет считать это другим приложением.

## Настройки (необязательно)
```bash
defaults write com.smartum.SmartumSwitch HotkeyKeyCode -int 113   # клавиша ручного исправления: 113=F15/Pause, 105=F13, 107=F14
defaults write com.smartum.SmartumSwitch SwitchDelayMs -int 60     # пауза после переключения раскладки, мс
defaults write com.smartum.SmartumSwitch ReplayMode keys           # перепечатывать клавишами (по умолчанию — Unicode-символами)
```

## Удаление
Меню **S** → «Выйти из SmartumSwitch» → (если включали) снять «Запускать при входе» до выхода → удалить
`~/Applications/SmartumSwitch.app`, папки `~/Library/Application Support/SmartumSwitch` и `~/Library/Logs/SmartumSwitch`,
убрать SmartumSwitch из «Универсального доступа» и «Мониторинга ввода» кнопкой «–».

## Устройство
| Файл | Что |
|---|---|
| `Sources/Core.swift` | ядро (правила `core/RULES.md`), только Foundation — тестируется и на Linux |
| `Sources/Engine.swift` | CGEventTap, буфер слова, исправление/откат, удержание клавиш на время исправления, Pause |
| `Sources/Mac.swift` | коды клавиш, отправка событий, раскладки (TIS, UCKeyTranslate), проверки полей пароля (AX) |
| `Sources/App.swift` | значок в строке меню, разрешения, исключения, журнал, автозапуск (SMAppService) |
| `vendor/hunspell/` | hunspell 1.7.2 (MPL 1.1 / LGPL 2.1 / GPL 2) — та же проверка слов, что на Linux и Windows |
| `build.sh` | сборка `.app` на Mac через Command Line Tools |
| `tests/test-on-linux.sh` | проверка Swift-ядра на Linux (171/171) |
